# 显式会话用量与额度快照

从本地扩展的事件重放、字段兼容、周期统计和额度快照算法提取的独立Node.js组件。保留快照/增量更新、请求去重、日周月年/每日统计及模型分组；只接收明确提供的输入，不读取应用默认目录。

Node.js 20或以上，无第三方运行依赖：

```sh
node cli.mjs example.json
npm test
```

输入为`events`数组，事件合同为初始`{kind:0,v:{requests:[]}}`或更新`{kind:1或2,k:[路径],v:值}`。库入口`recordsFromSession(content, options)`接收JSONL文本。必须指定`reasoningMode`：`included`表示推理计数已含在输出中，`additional`表示另外相加。缺失计数为null，统计同时返回已知合计和缺失数，零不等于缺失。

`rates`是调用方显式提供的每百万输入/输出单位估算价格，`multipliers`是显式统计权重；未配置即未知，没有内置厂商价格、倍率、订阅额度或账户信息。金额使用浮点估算，不作为账单。输出不含提示词、回复或原始会话/请求/模型标识，标识改为摘要；这不是对任意输入输出的匿名性保证。

`now`必须明确提供，`offsetMinutes`默认UTC，按固定偏移统一计算周期，不处理夏令时；未来记录单列，当前周期只统计截至now。额度只解析显式`quota`快照，并要求`quotaObservedAt`，标出过期或未来观测，不代表实时平台额度。

原扩展的VSCode界面、启动注册、目录扫描/文件监视、登录、网络查询、默认模型修改与账户数据库脚本全部排除。这是可运行组件，不是完整VSCode扩展。源码采用 MIT 许可证，见 LICENSE；第三方依赖仍适用各自上游许可。
